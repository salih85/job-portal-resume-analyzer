This project is a full-stack AI-based Job Portal and Resume Analyzer designed to automate and streamline the recruitment process.
It provides separate dashboards for Job Seekers, Recruiters, and Admins, enabling efficient job posting, application management, and intelligent resume screening.

The system uses Natural Language Processing (NLP) techniques to analyze resumes, match them with job requirements, and assist recruiters in identifying suitable candidates faster and more accurately.
